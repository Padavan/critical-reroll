# Critical reroll

React rewrite of the old ionic app Critical Roll: https://github.com/elemorelli/CriticalRoll

Simple web application to generates Critical and Fumble effects for tabletop RPGs.


# How to develop

`npm install` - to install dependencies

`npm start` - development build run on localhost:3000

`npm run build` build artifacts for production serve

`npm run lint` to run linting

`npm run typecheck` - to run tsc and check types

no tests
